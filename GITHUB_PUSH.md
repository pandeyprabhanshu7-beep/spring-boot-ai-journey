# Repository workflow

Repository: https://github.com/pandeyprabhanshu7-beep/spring-boot-ai-journey

Clone, install JDK 17+ and Maven, then run:

```bash
git clone https://github.com/pandeyprabhanshu7-beep/spring-boot-ai-journey.git
cd spring-boot-ai-journey
mvn verify
cd 01-ai-qa
mvn spring-boot:run
```

For future work use a feature branch, run tests, and push genuine changes with meaningful commit messages. Never commit credentials or fabricate dates.

## ChatGPT Project setup

Create a ChatGPT Project named Java AI GitHub Journey, upload MASTER_PROMPT.md and the project ZIP, and paste PROJECT_INSTRUCTIONS.md into its instructions. This repository does not create a ChatGPT Project container automatically. Future chats need these files or this repository URL to reuse the baseline.
